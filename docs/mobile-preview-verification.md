# 모바일 배치와 미리보기 설정 · 1.6.2

## 변경 범위

모바일 상단에는 덱 이름·저장·더보기를, 하단에는 카드 목록·편집·미리보기·보관함을 배치한다. 더보기에서 저장·보관함·JSON 가져오기 중복을 제거하고, 기존 불러오기 창으로 파일을 가져온다. 인스펙터 항목을 접은 상태는 필드를 수정해도 유지한다. 보관함은 검색과 자료를 먼저 보여주고 폴더·JSON 관리 도구는 접어 둔다.

카드와 이펙트 제작기의 미리보기 종료 시간은 0.1~3600초다. 반복을 끄면 끝에서 멈추고 다시 재생하면 처음부터 시작한다. 반복을 켜면 지정한 구간을 이어서 재생한다. 재생 중 시간 막대의 끝은 늘어나지 않는다.

전용 ‘고화질 6초 보기’를 제거하고 자동·150·300·600·직접 입력 DPI로 대체한다. 직접 입력은 50~600 DPI이며, 수동 설정은 재생 중에도 낮추지 않는다. 큰 카드에서는 여백을 포함한 1600만 픽셀·축당 8192픽셀 제한을 적용하고 실제 DPI를 표시한다. 인쇄 DPI는 기존 설정을 사용한다.

보기 설정은 브라우저에 기억하고 카드 화면과 이펙트 제작기 사이에 즉시 동기화한다. 프로젝트 JSON·이펙트 실행 취소 기록에는 넣지 않는다.

## 재현과 검증 범위

```text
npm run build
node scripts/build-harness.mjs
node --test --test-concurrency=1 tests/preview-settings.spec.mjs tests/mobile-layout.spec.mjs
npm test
```

`npm run verify:effects`에도 새 설정과 모바일 배치 검사를 포함했다. 실패·생략·집계 누락을 통과로 바꾸지 않는 기존 검증기 규칙을 유지한다.

새 동작은 먼저 실패하는 테스트로 재현했다. 종료·반복·DPI 계산, 설정 동기화, 입력 범위, 원본 JSON 보존, 모바일 중복 메뉴와 인스펙터 상태, 가로 화면의 재생·설정 접근성을 확인한다. 기존 고화질 버튼을 찾던 검사는 새 DPI·설정 경로로 변경했다.

독립 리뷰에서 두 미리보기 창의 설정 덮어쓰기와 가로 화면의 설정창 잘림을 확인했다. 각각 실패 재현 후 수정했으며 재검토에 남은 확인된 지적은 없다.

브라우저 검사는 별도 Microsoft Edge 프로필에서 수행한다. 390×844와 844×390의 터치 화면을 자동 검사하고 화면을 살폈다. 실제 휴대전화·프린터와 사용자 Google 로그인·운영 카드 쓰기는 이 변경의 검증 범위에 포함하지 않는다. 서버 SQL·인증·권한 규칙은 수정하지 않았다.

## 최종 검사 결과 · 2026-10-22

`npm test`는 총 1,071개 중 **1,070개 통과·실패 0개·생략 1개**로 종료했다(1,477.55초). 생략한 항목은 `CARD_BG_MODEL_DIR`에 고정된 실제 U2NetP 모델 파일이 필요한 추론 검사다. 모델 없이 실행된 다른 배경 제거 검사를 실제 모델 추론 검증으로 대신하지 않는다.

실행 초반에 모바일 더보기의 중복 JSON 가져오기를 숨기는 CSS를 보완했다. 영향받는 모바일 검사는 그 이후 전체 실행에서 통과했고, 해당 파일을 별도 실행한 결과도 2/2 통과했다. 전체 실행 동안 모든 입력 파일이 고정돼 있었다고 주장하지 않는다. 관련 재검사 19/19 통과 결과도 별도로 보관하며 전체 건수에 더하지 않는다.

전체 실행 로그는 `artifacts/qa/mobile-preview-full.log`에 있다. 재생 중에도 저장한 장면을 사용하는 실제 300 DPI A4 양면 PDF 픽셀 비교, 오프라인 저장·폴더·JSON 가져오기·키워드·그림·레이어 회귀를 포함한다. 이 변경 이후 별도 서버 통합 검사는 다시 실행하지 않았다.
