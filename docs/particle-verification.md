# PP Monster 1.6.3 · 파티클 통합 검증

2026-10-22 KST. 기능 커밋은 `453c6f7`이며, 파티클 추가·이동 경로·기본 이미지·독립 보관함과 저장 파일 호환을 포함한다. 이전 공개 버전 1.6.2보다 높은 버전으로 패키지·업데이트 정보·HTML을 함께 갱신했다.

## 자동 검사

- 배포 준비본의 기본 검사 **536/536** 통과. 서버 검증·모델·이동 좌표·저장 왕복·복구·권한 기대값을 포함한다.
- 실제 Edge의 업데이트·오프라인 검사 **15/15** 통과. 새 HTML 다운로드, 기존 작업과 실행 취소 유지, 오프라인 편집·그림·저장·다시 열기·A4 PDF 내보내기를 포함한다.
- 기능 구현 단계에서는 통합 조작·기본 이미지·사용자 스프라이트 시트·중첩 이미지 선택·모바일·텍스트/프레임 대상·보관함 저장 실패 복구·실행 취소와 실제 A4 PDF 고정 장면의 반복 픽셀 일치를 검사했다. 보관함 재진입 회귀 두 건은 수정 후 원래 검사로 재통과했다. 독립 코드 리뷰도 통과했다.
- `src/`·`dist/` 비밀 Supabase 키 검사와 변경 파일 공백 검사가 통과했다.

기본/업데이트 검사의 원본 로그는 Git에서 제외한 `artifacts/qa/particle-release-unit.log`, `particle-release-browser.log`에 있다. 기능 검사 로그와 화면 자료도 같은 폴더에 보관했다. 이번 배포에서 모든 브라우저 검사를 다시 실행한 것은 아니다.

## 운영 API

사용자의 ‘서버에까지’ 승인 후 기존 `api` 함수만 배포해 ACTIVE revision 3을 확인했다. DB 마이그레이션이나 기존 작업 자료 변경은 없다.

배포 전 운영 소스를 별도로 내려받았을 때 새 이동 설정을 `invalid-work`로 거부하는 것을 재현했다. 배포 뒤 운영 소스를 다시 내려받아 나선 이동을 넣은 카드·공유 이펙트의 허용, 범위를 벗어난 설정 거부, 테스트한 로컬 검증 번들과의 SHA-256 일치를 확인했다. [운영 소스 검증 결과](evidence/cloud/particle-server-model.json).

이는 운영 계정의 실제 카드 쓰기 검증을 뜻하지 않는다. Google 계정 로그인이나 사용자 프로젝트에는 접근하지 않았다. 비밀 키는 클라이언트 코드·배포 HTML·로그·Git에 넣지 않았다.
