# 이미지 자르기와 공용 에셋 보관함

사용자 요청: 속성 선택을 하나의 펼침 메뉴로 모으고, 이미지를 잘라 저장하고 재사용하며, 첨부한 아이콘 모음 같은 이미지를 스프라이트 시트로 나누어 사용할 수 있게 한다. 기존 카드 제작과 로컬 폴더 기억 기능을 보존한다.

## 동작

- 상단 `에셋 보관함`에서 여러 PNG/JPEG/WebP 파일을 가져오고 이름 검색, 이름 변경, 개별 삭제, PNG 받기를 제공한다. 덱을 바꿔도 재사용하는 공용 보관함이다.
- 원본 또는 보관된 이미지를 열어 `영역 자르기` 또는 `스프라이트 시트`를 사용한다. 영역은 이미지 위에서 드래그하거나 픽셀 좌표와 크기로 지정한다. 시트는 행/열, 셀 크기, 시작 위치와 간격을 조절하며 원하는 셀만 선택해 일괄 저장한다.
- 조각은 원본 해상도의 새 PNG로 만든다. 원본과 기존 카드의 그림을 수정하지 않으며 투명도를 유지한다. 흰 배경은 자동으로 지우지 않는다.
- 카드 그림 교체, 선택 이미지 교체, 새 이미지 요소 추가, 이펙트의 입자 이미지, 키워드 아이콘에서 보관함을 사용할 수 있다. 카드/이펙트는 복사한 이미지를 자신의 JSON에 포함하므로 보관함 삭제나 다른 컴퓨터에서도 유지된다.
- 보관함은 브라우저에 임시 보관하고, 연결된 저장 폴더에 별도 `에셋/asset-library.json`으로 저장한다. 이미 데이터 안쪽인 위치에는 `작업실 데이터`를 추가 생성하지 않는다. 명확하지 않은 하위 폴더는 그 위치에 보관함 파일을 직접 저장한다. 프로젝트/카드 전용 하위 폴더에서는 상위 데이터 폴더 연결을 안내한다.
- 폴더 권한이 없을 때는 임시 보관 상태와 구체적인 사유를 표시하고 기억한 폴더 다시 연결을 제공한다. 보관함 JSON 내보내기/가져오기로 다른 친구에게 공유할 수 있다. 디스크 충돌과 변경된 폴더에 대한 오래된 비동기 저장을 거부한다.
- 속성은 닫힌 메뉴에 현재 선택한 이름만 표시하고 펼치면 여섯 속성을 함께 선택한다. 멀티 선택과 아이템의 속성 없음, Variant 상속, 실행 취소를 보존한다.

## 제약

오프라인 단일 HTML을 유지한다. 개인 카드·그림·레이어 파일을 변경하지 않는다. 외부 서비스와 새 런타임 의존성을 추가하지 않는다. 큰 이미지와 과도한 셀 수를 명확한 제한과 메시지로 처리한다. 잘라내기 결과의 너비·높이는 양의 정수 픽셀이다. 저장 실패나 취소를 성공으로 표시하지 않는다.

## 검증

투명/반투명 픽셀의 원래 값, 시트 간격·잘못된 좌표·빈 선택, 새 덱에서 재사용, 원본 보존과 보관함 삭제 후 카드 유지, 이펙트 임시 편집 취소, 폴더 재연결·충돌·중첩 방지, JSON 왕복을 검증한다. 첨부 이미지는 로컬 검증 입력으로만 쓰고 배포에 포함하지 않는다.
