# GPU Bloom Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Review with superpowers:requesting-code-review before delivery.

**Goal / accepted scope:** The user's “Gpu로 해줘” moves expensive bloom blur calculations to the GPU by default in the existing offline HTML studio.

**Architecture:** Keep synchronous card/print rendering and existing CPU threshold extraction, crop, alpha compositing and fallback. A lazy shared WebGL2 engine performs the six fractional box passes in RGBA32F textures, retains bounded reusable resources, and reports the backend actually used. No new dependencies or changes to project JSON.

**Tech Stack:** JavaScript, WebGL2 / EXT_color_buffer_float, Canvas2D, Edge browser tests.

**Spec:** Accepted scope above and constraints below; this bounded change follows the existing renderer contract.

## Global Constraints

- Preserve independent returned surfaces, source artwork, alpha, mm/DPI geometry and saved print frames.
- CPU fallback must remain pixel exact against the existing oracle; GPU output must be deterministic, with measured alpha/premultiplied channel error at most approximately one 8-bit step.
- Handle unavailable GPU/float targets, context loss/restoration, allocation errors and oversized jobs without breaking editing or printing.
- Use one lazy context, bounded texture memory, and no network/runtime dependency. Never reload the user's working browser tab.
- Benchmark against v1.3.0's optimized CPU path, including upload/readback, and distinguish microbenchmarks from application frame rate.

## Review Focus

- Fractional radii and work edges: full finite halo, no unintended wrap or orientation change.
- Tiny canvases / low alpha: no NaNs, source mutation or transparency fringes.
- Context loss and unsupported hardware: reliable CPU output and accurate status.
- Repeated renders and size changes: bounded resource reuse without stale pixels.
- Selected playback, frozen cache and 300 DPI print: deterministic and equal within each active backend.
