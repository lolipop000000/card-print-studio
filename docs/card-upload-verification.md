# 카드 한 장·JSON 업로드 검증 — 1.6.5

카드 목록에 **카드 올리기 / JSON 카드 올리기**를 추가했습니다. 선택 카드의 필요한 그림·원본 레이어·키워드·이펙트를 기존 `work.create` API로 비공개 저장합니다. 프로젝트 JSON은 한 장을 선택하며 현재 덱과 편집·실행 취소·클라우드 연결을 바꾸지 않습니다. 중복은 덮어쓰기·추가·취소를 확인하고 덮어쓰기는 기존 공개 상태를 유지합니다.

## 검사

- 구현 전 브라우저 검사는 업로드 버튼 부재로 실패했습니다.
- 인증 대기 중 선택을 바꾸면 다른 카드가 올라가는 회귀를 재현한 뒤, 클릭 시점의 카드와 불변 프로젝트를 캡처하도록 수정했습니다.
- 브라우저 검사 9개: 필요한 리소스만 전송, JSON 파일 선택, 다중 카드 JSON 선택, 중복 처리, 비회원 차단, 계정 전환, 클릭 시점 보존, 실패 재시도·동시 수정 충돌, 모바일 배치.
- 기본 검사 전체와 클라우드·보관함·모바일·오프라인·업데이트 검사: **614 / 614 통과**, 생략·취소 0개.
- 별도 코드 리뷰에서 남은 중요한 문제 없음.
- 기존 서버 API와 검증기를 사용하며 서버 코드·SQL 변경은 없습니다.

## 파일 감시 알림과 대조

Windows의 파일 감시가 폴더 상태 알림도 코드 변경으로 판정해 원본 실행 보고서의 최상위 상태는 `FAIL`입니다. 동기화 밖의 동일한 복사본에서도 검사 단계는 모두 통과했고 감지된 항목은 `src/printing`, `src/render/effects`, `src/ui` 폴더의 `change` 알림뿐이었습니다. 기존 보고서를 성공으로 수정하지 않았습니다.

별도의 코드 대조에서 모든 알림 대상이 폴더인지, 복사 전·검사 후·현재 입력 코드와 검사한 HTML이 같은지 확인했습니다. 결과는 `artifacts/qa/card-upload-release-gate.json`, 원본 보고서는 `artifacts/qa/card-upload-cloud-report.json`에 보관합니다. 감시기 자체의 폴더 알림 오탐은 남아 있습니다.

- 입력 코드 SHA-256: `9b2460e7ab386ec455562203af76629543b68ce89b51d178a9f43dfe280093e1`
- HTML: 5,652,598 bytes
- HTML SHA-256: `94652d9ee8aa0e548a25acfca2d4798ff9568f2bb63eeb393c518888f2ce1f37`

배포 후 버전 정보·GitHub HTML·다운로드 파일·웹 배포 파일의 해시와 실제 모바일 화면을 `artifacts/qa/verify-card-upload-publication.mjs`로 대조합니다. 실제 로그인 계정의 자료를 생성하거나 변경하는 검사는 하지 않습니다.
