# 이펙트 품질 규칙

2026-10-15 사용자 요청: 색수차를 고치고, 자료와 리뷰를 바탕으로 다양한 시각 효과를 자율적으로 추가·개선한다. 기존 작업실의 오프라인 편집·인쇄 목적을 유지한다.

1. 노출한 조절은 유효 범위에서 실제 시각적 차이를 만든다. 입력창과 모델의 최소·최대는 같다. 작동하지 않는 옵션은 숨긴다.
2. 검정·짙은 한글, 흰색·컬러, 반투명 선화와 구멍 있는 그림을 검사한다. 색수차는 검정에서 유채색 프린지가 보여야 하며, 없는 RGB 채널로 검정 잔상을 만들지 않는다. RGB 분리와 두 색 프린지는 선택할 수 있다.
3. 필터는 입력을 수정하지 않고 새 surface를 반환한다. 강도·거리의 무효값은 픽셀까지 같고 투명 입력은 투명하다. 표면 재질의 알파는 보존하며 입체 두께·색수차의 바깥 픽셀과 글리치의 윤곽 이동은 명시적으로 검사한다.
4. 크기는 mm, 무작위는 저장된 seed·레이어 ID, 애니메이션은 명시한 시간만 사용한다. 정지 레이어는 시간에 영향받지 않는다. 견본에도 고정 시드·시간을 쓴다.
5. 흰 종이에 어두운 윤곽과 명암이 남는 프리셋을 만든다. 기본 밝은 재질에 얇은 진한 외곽을 먼저 사용한다. 금속·홀로그램은 인쇄되는 정지 색무늬다.
6. 원본 글자·키워드·그림·paintings와 Variant 상속을 보존한다. 글자 보호·필터 범위·불투명도는 공통 합성기에서 한 번만 적용한다. 자기 글자 보호 제외를 바꾸지 않는다.
7. 효과가 늘면 검색·범주·실제 렌더 견본을 제공한다. 한글 조합 입력 중 검색창을 교체하지 않는다. 선택 대상 확대와 눌러서 원본 비교는 저장 프로젝트를 바꾸지 않는다. 비교를 놓거나 닫으면 원래 미리보기로 돌아온다.
8. 버그와 새 핵심 동작은 실제로 실패하는 회귀검사를 먼저 본다. 독립 리뷰의 Critical/Important는 수정하고 재현 검사를 남긴다. 관측 증거와 제안을 구분한다.
9. 완료 전에 변경 범위에 맞는 자동 검사를 실행한다. 렌더·인쇄 변경은 150/300dpi 대표 이미지와 같은 시간의 실제 A4 PDF, 전달 HTML도 확인한다. 통과한 검사를 이유 없이 반복하지 않으며 전반적인 회귀 우려가 있으면 전체 검사를 선택한다. 브라우저·PDF 증거를 실제 프린터 실험이라고 표현하지 않는다.

10. 외곽선은 0보다 큰 알파를 불투명 실루엣으로 바꾸지 않는다. 알파 1/64/128/255와 부드러운 경계·원형 대각선을 검사하고, 확장분만 premultiplied 색으로 더한다. 같은 알파의 중심은 진해지지 않는다.
11. 입자는 서로 다른 모양과 흰 종이에서 남는 윤곽을 갖는다. 시작·수명 끝과 빛 꼬리는 투명해진다. 새 조절값의 변화·정지·같은 시간 재현, 7pt 한글과 300dpi PDF를 함께 검사한다.
12. 스킬 참조는 현재 카드의 ID와 본문 범위로 연결한다. 실제 이름을 문장에 보관하고 표시할 때 최신 이름을 반영한다. 이름이 같은 다른 스킬, 조합 입력·반복 문장 편집, 키워드 이름 변경을 검사한다.
13. Variant의 기술 본문과 참조 범위는 함께 변경한다. 상속·복제에서 ID를 재매핑하고, 삭제된 참조는 읽을 수 있는 본문으로 남겨 저장을 막지 않는다. 그림 원본·예전 파일은 보존한다.

14. 다중 선택은 편집 상태로만 보관하며, 취소된 드래그는 저장과 실행 취소 기록을 바꾸지 않는다. 묶음은 간격을 유지해 함께 경계에 멈춘다. 기술 요소 복제 뒤 자동 배치가 원본이나 사본을 없애지 않는지 검사한다.
15. 바로 인쇄는 입력 중인 값을 반영한 프로젝트 복사본으로 준비한다. PDF를 만들지 않고 전용 문서에 동일한 300dpi 고정 장면·mm 좌표·양면·재단선을 보낸다. 취소·반복·오류 정리와 마지막 부분 페이지를 검사하며 실제 프린터 증거와 구분한다.

16. 이름 전용 효과는 실제 이름의 글자만 마스크로 사용한다. 접두어·주변 문장·키워드는 움직이거나 다시 칠하지 않는다. 줄바꿈·정렬·빈 스타일의 기존 픽셀을 비교하고, 중첩 왜곡의 최종 글자 크기를 검사한다. 캐시가 따뜻해져도 이름별 인쇄 경고를 유지한다.
17. 커서·다중 선택·저장 파일 연결은 카드 규칙 자료와 분리한다. 비동기 저장 완료는 기록한 스냅샷의 저장 기준을 갱신하고, 불러오기 창 취소 뒤의 작업은 덮어쓰지 않는다. 폴더 권한 거부를 저장 성공이나 다운로드로 숨기지 않는다.
18. 한 장 파일은 카드가 쓰는 자료만 포함하고 가져오기 전에 전체 검증한다. 내부 ID·참조·그림 원본을 재매핑하며, 키워드 충돌과 손상된 파일은 현재 덱을 부분 변경하지 않는다.

19. 모양만 다른 입자는 이미지·도형 입자로 묶는다. 기존 파일의 효과 종류를 삭제하거나 강제로 변환하지 않고, 새 추가 목록만 정리한다. 사용자 이미지의 비율·투명도와 수명에 따른 크기·색·알파를 유지한다.
20. Bloom은 밝기 기준을 넘는 빛만 추출하고 알파에 비례해 퍼뜨린다. 새 흐림·일렁임은 premultiplied 색으로 보간하고 원본을 바꾸지 않는다. 강도/거리 0, 투명 구멍과 150/300dpi를 검사한다.
21. 입자 이미지 가져오기는 적용 전 임시 보관한다. 읽는 중 적용·저장을 막고, 확인창을 열어도 읽기 결과를 유실하지 않는다. 파일 선택창 취소가 이펙트 창을 닫지 않아야 한다. 카드 파일은 참조한 입자만 포함하고 ID를 다시 연결한다.
22. 이펙트 실행 취소는 카드 기록과 별도로 최근 100단계를 유지한다. 입력 중 숫자는 먼저 검증하며 무효 입력 취소가 이전 작업을 소비하지 않아야 한다. 실제 마우스와 키보드, 대상 전환·취소·다시 열기를 검사한다.
23. 재생 시간에 전역 6초 나머지 연산을 쓰지 않는다. 인쇄는 실제로 확인한 정지 장면을 저장하고 6초 이후도 동일 픽셀로 재현한다. 파동·입자는 시작보다 작은 끝 크기와 끝 크기 0을 지원한다.
24. 아이템의 원형 양초 표시는 항상 유지한다. 아이템은 기본 속성 없음과 무속성을 구분하고 필요하면 0~6개 속성을 부여한다. 몬스터는 1~6개를 유지한다. 양초도 보이는 요소와 동일하게 클릭·영역 선택되며 예전 단일 속성과 Variant 상속, 빈 선택의 독립 변경, 직접 배치한 영역과 그림 원본을 보존한다. 배지가 없던 저장 파일에는 안정적인 ID로 복원한다.
25. 브러시 크기는 입력·커서·실제 픽셀에서 같은 0.1~4096 px 범위를 쓴다. 레이어 드래그는 한 번의 실행 취소로 복원하고 바깥 놓기·Esc·취소는 원본 픽셀과 기록을 바꾸지 않는다.
26. 그림과 이펙트는 공통 26종 native 혼합 목록을 사용한다. 구버전에서 모드를 생략하면 일반으로 열고, 알 수 없는 명시값은 위치와 값을 안내하며 거부한다. 투명 합성·불투명도·표시/잠금·필터 범위·글자 보호·저장/재열기·실행 취소·같은 시각의 PNG/PDF를 확인한다. 그림 합치기가 배경 의존 혼합을 바꾸면 원본을 보존하고 정확히 안내한다.

27. 이미지 자르기·분할 재생·독립 배율·뒤집기·회전 중심은 원본 자산을 바꾸지 않는다. 새 선택값을 생략한 예전 입자는 같은 픽셀을 유지한다. 고정 배치와 입자 배치, 시트 컷의 경계·고정 인쇄 시각·투명 구멍·변경된 캔버스의 캐시를 검사한다.
28. 드래그 손잡이는 렌더러가 사용하는 영역·글자 높이·회전 중심을 공유한다. 확대·스크롤·자르기·회전에서도 같은 대상을 가리키며, 한 조작은 한 기록이고 Esc·포인터 취소는 자료와 기록을 바꾸지 않는다. 방향키 한 픽셀은 300dpi의 25.4/300mm로 고정하고 글자 입력 중에는 가로채지 않는다.
29. 글자 크기·기울임·자간·줄간격은 줄바꿈 측정과 실제 그리기에 함께 적용한다. 일반 글자·키워드·이름 전용 스타일도 같은 규칙으로 계산한다. 자동 기술 배치는 실제 높이로 아래에 이어지며 높이를 강제로 압축하거나 최소 글자보다 줄이지 않는다. 그림·수동 요소는 보존하고 정렬은 선택 요소만 변경한다.
30. 잘림·작은 글자·표시 누락 등 렌더 안내는 인쇄를 막지 않는다. 100dpi 사전 점검과 실제 300dpi 앞면·뒷면 출력 모두 같은 정책을 사용하며, 원본 내용이나 좌표를 몰래 바꾸지 않는다. 잘못된 자료와 만들 수 없는 용지 배치는 오류로 구분한다.

31. JSON 드롭은 파일 이름 대신 실제 덱/카드 형식을 판별하고 기존 검증·불러오기 경로를 사용한다. 현재 작업 교체 확인, 잘못된 JSON·그림 해독 실패·복수 파일·중복 읽기·늦은 완료·편집 창 보호를 검사하고 일반 글자 드래그를 가로채지 않는다.
32. 작은 그림의 확대 선명도는 화면 캡처 픽셀로 확인한다. 보기 배율 때문에 원본·레이어·저장 PNG·카드 적용 그림을 리샘플하지 않는다. 그리기용 픽셀 맞춤과 확대 표시 설정은 분리한다.
33. 브러시 프리셋은 실제 크기·경도·불투명도·붓 모양을 바꾼다. 대칭의 중심은 알파를 중복 누적하지 않고, 투명 영역 보호는 반투명 픽셀의 알파도 보존한다. 선화 참조 채우기는 합성 그림으로 경계를 찾되 현재 레이어만 바꾼다. 그라데이션의 미리보기·확정·취소·실행 취소와 선택 영역·잠금·기존 기본 픽셀을 검사한다.

## 2026-10-21 별빛 기준

- 네 광선은 외곽으로 갈수록 알파가 감소하고 끝에서 투명해진다. 중심의 밝기·색과 레이어 불투명도를 보존하며 합성 경계에 검은 선을 만들지 않는다.
- 한 조합은 최대 별 크기를 덮는 고정 해상도의 빛 이미지를 공유한다. 서로 다른 크기의 별이나 반짝임 때문에 매 프레임 캐시를 교체하지 않는다. 캐시 픽셀 저장소는 16 MiB 이내로 제한하고 별빛 생성 중 픽셀 읽기와 필터를 사용하지 않는다.
- 같은 시드·시간의 반복 픽셀과 수명 경계의 연속성, 흰 용지의 투명 합성 및 실제 300 DPI PDF의 고정 프레임을 검사한다.

## 조사 근거

- [ESA/Hubble 시리우스](https://esahubble.org/images/heic0516a/), [프록시마](https://esahubble.org/images/potw1343a/): 4각 별빛의 밝은 중심, 가늘고 긴 광선과 부드러운 빛 번짐을 참고한다. 망원경 사진의 회절 형태를 미술 참고로 사용하며 사진이나 외부 코드는 배포에 포함하지 않는다.

- [Adobe 레이어 스타일](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/apply-layer-effects/layer-style-effects-and-options-overview.html): 양각, 안쪽 그림자·발광과 질감을 독립 조절 가능한 효과로 구성한다.
- [Unity 색수차](https://docs.unity3d.com/Packages/com.unity.postprocessing@3.4/manual/Chromatic-Aberration.html): RGB 경계 분리와 프린지 색 선택을 구분한다.
- [PixiJS 필터 목록](https://pixijs.io/filters/docs/): 입체·글리치·주사선·필름 질감의 조합 방향을 참고한다.
- [SideFX 색수차](https://www.sidefx.com/docs/houdini/nodes/cop/chromaticaberration.html): 채널 이동과 분광 효과를 구분한다.

- [Canvas globalAlpha](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/globalAlpha): 생성 도형의 알파와 레이어 불투명도를 함께 반영한다.
- [Unity Color over Lifetime](https://docs.unity3d.com/Manual/PartSysColorOverLifeModule.html): 입자의 수명에 따른 색·투명도 곡선과 사라지는 꼬리 방향을 참고한다.

- [Unity Bloom](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/post-processing-bloom.html): 밝기 기준·강도·퍼짐·색을 독립 조절한다.
- [Khronos EXT_color_buffer_float](https://registry.khronos.org/webgl/extensions/EXT_color_buffer_float/): 지원을 확인한 RGBA32F 대상으로 계산하고 RGBA/FLOAT로 읽어 약한 빛을 중간 단계에서 양자화하지 않는다.
- [WebGL best practices](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices): 선택적 확장과 자원 제한에 맞춰 대체 경로를 두고, 텍스처·프로그램을 재사용한다. 현재 동기 렌더러와 연결할 때는 여섯 단계가 끝난 뒤 한 번만 CPU로 읽는다.
- [Chrome Canvas2D](https://developer.chrome.com/blog/canvas2d/), [Canvas willReadFrequently 설계](https://github.com/fserb/canvas2D/blob/master/spec/will-read-frequently.md): 그림용 캔버스는 하드웨어 가속이 가능한 설정으로 만들고 자주 읽는 분석용 캔버스는 분리한다. 실제 후단 선택은 브라우저가 담당하므로 설정값만으로 하드웨어 사용을 단정하지 않는다.
- [Unity Size over Lifetime](https://docs.unity3d.com/6000.0/Documentation/Manual/PartSysSizeOverLifeModule.html): 입자의 수명에 따라 크기를 늘리거나 줄이는 조절 체계를 참고한다.
- [Adobe Distort effects](https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/distort-effects.html): 거리·간격·방향을 나누는 변형 조절을 참고한다. 이 작업실의 교차 일렁임은 부드러운 교차 사인파이며 난류 노이즈 구현을 뜻하지 않는다.

- [WHATWG Canvas 합성](https://html.spec.whatwg.org/multipage/canvas.html#compositing), [W3C Compositing and Blending](https://www.w3.org/TR/compositing-1/#blending): 표준 혼합과 Porter-Duff 합성을 사용하고 일반 합성의 기본값과 alpha 동작을 유지한다.

- [WHATWG Canvas 글자 스타일](https://html.spec.whatwg.org/multipage/canvas.html#text-styles): 글꼴·자간을 측정과 그리기에 일관되게 적용한다.

외부 코드·이미지·패키지를 복사하지 않고 개념과 조절 체계만 참고한다.
