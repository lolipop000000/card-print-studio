# PP Monster

## 클라우드 저장과 공유

배포된 웹 주소에서 로그인하고 관리자 승인을 받으면 내 작업을 클라우드에 저장하고 공개할 수 있습니다. 자동 저장은 나만 보는 초안이며, **저장**하면 공개본과 버전 기록이 갱신됩니다. 공개 목록에서 다른 친구의 작업을 보고 내 사본으로 가져올 수 있습니다. 그림·키워드·이펙트·카드 서식도 독립 사본으로 공유합니다.

**에셋 보관함** 안의 **이미지 / 내 자료 / 공개 자료 / 휴지통**에서 모든 자료를 찾습니다. 내 자료와 공개 자료는 제목·만든 사람 검색과 종류 필터를 지원합니다. **내 계정 설정**을 펼치면 Google 로그인, 닉네임 변경, 승인 상태, 사용량과 로그아웃을 관리할 수 있습니다. **PC 작업 올리기**도 보관함에서 엽니다. 작업 화면의 저장 실패·충돌 표시를 누르면 계정 설정의 해결 방법으로 이동합니다.

승인 전, 오프라인 파일 실행 또는 클라우드 연결이 없는 배포본에서는 기존 파일·폴더 저장을 사용합니다. 연결이 끊겨도 편집 내용은 로컬 복구에 남습니다. 준멤버는 카드 10장·이미지 15MiB, 멤버는 120장·150MiB까지 저장합니다. **PC 작업 올리기**에서 기존 자료를 선택해 옮길 수 있습니다.

관리자 설정은 [cloud-setup.md](docs/cloud-setup.md), 승인·백업·복구는 [cloud-admin.md](docs/cloud-admin.md)를 참고하세요. `cloud.json`에는 운영 서버의 공개 주소와 공개 키만 들어갑니다.

PP Monster는 친구가 만든 카드게임의 카드를 편집하고, 직접 그림을 그려 A4에 인쇄하는 도구입니다.

## 바로 열기

[웹 작업실 열기](https://lolipop000000.github.io/card-print-studio/)에서 클라우드 저장과 공유를 이용하세요. 오프라인으로 쓰려면 [최신 작업실 HTML 받기](https://github.com/lolipop000000/card-print-studio/releases/latest/download/card-print-studio.html)에서 파일을 받은 뒤 Edge 또는 Chrome으로 여세요. [전체 배포 파일과 변경사항](https://github.com/lolipop000000/card-print-studio/releases/latest)도 받을 수 있습니다. 개발 폴더에서는 `dist/card-print-studio.html`을 여세요. 로컬 편집·저장·인쇄에는 인터넷, 설치, 계정, 개발 서버가 필요하지 않습니다. 한국어 폰트와 PDF 생성기가 HTML 안에 들어 있습니다. 자동 배경 제거는 처음에 처리 도구를 내려받습니다.

작업은 상단 **저장 / Ctrl+S**로 로컬 폴더에 보관하세요. 처음에는 **HTML이 있는 폴더**를 선택하고 읽기·쓰기 접근을 허용합니다. 그 안에 `작업실 데이터` 폴더를 만듭니다. 카드, 공통 뒷면, 키워드와 아이콘, 내 이펙트, 그림 원본과 레이어를 덱별 `.card-project.json` 파일 하나에 담습니다. HTML 자체는 바꾸지 않습니다. **불러오기 → JSON 파일 선택**으로 덱 파일을 직접 열거나, **저장 폴더 선택**으로 폴더의 덱 목록을 엽니다. 연결된 폴더가 있으면 목록도 바로 보입니다. 폴더 선택창에는 JSON 파일이 표시되지 않으므로 파일을 열 때는 **JSON 파일 선택**을 사용하세요.

인쇄할 때는 상단 **바로 인쇄** 또는 **Ctrl+P**를 누릅니다. PDF 파일 없이 브라우저 인쇄창이 열립니다. 인쇄 배율은 **100%**, 머리글·바닥글은 끄세요.

## 새 버전 받기

상단 **새 버전**에서 현재 버전(1.6.1), 변경사항, 새 HTML 받기와 현재 덱 백업을 이용합니다. 새로 연 작업실의 기본 배포 주소는 이 공개 GitHub 저장소에 연결되어 있습니다. 예전 버전에서 빈 주소가 저장되어 있어도 기본 GitHub 주소를 자동으로 채웁니다. 직접 지정한 다른 주소는 유지하며, 이 버전에서 **연결 해제**를 누르면 다음 실행에서도 연결을 해제한 상태로 둡니다.

- **새 버전 확인**을 누르세요. 새 버전이 있을 때만 **새 버전 HTML 받기**를 표시합니다. 같은 버전과 이전 버전은 구분해서 안내합니다. 기존 버전에서 처음 연결하거나 연결을 해제한 경우 [새 버전 정보 주소](https://raw.githubusercontent.com/lolipop000000/card-print-studio/main/dist/update.json)를 복사해 배포 주소 입력칸에 넣으세요.
- **작업실을 열 때 새 버전 확인**은 직접 켤 때만 동작합니다. 켜지 않으면 확인 버튼을 누를 때만 접속합니다. 주소와 이 설정은 이 브라우저에 기억하며 카드 파일에는 넣지 않습니다.
- **현재 덱 백업**은 지금 열린 덱의 카드·그림 원본·레이어·키워드·이펙트를 JSON으로 내려받습니다. 다른 덱 파일까지 백업하지는 않으며, 폴더 저장의 미저장 표시와 실행 취소 기록은 유지합니다.
- 새 HTML은 파일로 내려받습니다. 현재 작업을 저장한 뒤, 받은 파일을 기존 작업실 폴더에 넣고 여세요. `작업실 데이터` 폴더를 유지하고 저장한 덱을 다시 불러오면 됩니다. 다운로드가 차단되면 구체적인 이유와 직접 다운로드 주소를 표시합니다.
- 창을 닫으면 진행 중인 확인·받기를 취소합니다. 다시 열어 재시도할 수 있습니다. **연결 해제**는 버전 확인 설정만 비웁니다.

인터넷이 없어도 기존 편집·저장·인쇄는 계속 사용할 수 있습니다. 업데이트 요청에는 카드와 그림을 보내지 않습니다. 새 버전 정보와 HTML은 공개 GitHub 저장소에서 받습니다.

## 고화질 6초 보기

카드 미리보기 또는 이펙트 편집기에서 **고화질 6초 보기**를 누르면, 현재 시점부터 6초 분량을 먼저 준비합니다. 준비가 끝나면 30fps 영상으로 재생합니다. 준비 중에는 진행률을 보고 취소할 수 있고, 재생 중에는 일시정지·구간 이동·반복 재생을 사용할 수 있습니다. Esc는 영상 창만 닫습니다.

기본 카드 크기는 300dpi(744×1039)로 준비하며 큰 카드에는 픽셀 상한을 적용합니다. 이펙트 편집기의 **선택 대상만 재생**과 적용 전 변경도 반영합니다. 영상 준비는 카드 파일, 인쇄 장면, 실행 취소 기록을 바꾸지 않습니다. 최신 Edge·Chrome의 로컬 파일에서 사용할 수 있으며, 영상 만들기를 지원하지 않는 브라우저에서는 이유를 표시하고 일반 재생을 계속 제공합니다. 이펙트가 인쇄 영역 밖에서 잘린다는 경고는 표시하지 않습니다.

## 자동 임시 보관과 작업 복구

카드·덱 내용을 수정하면 잠시 후 브라우저에 복구본을 보관하고 상단에 **임시 보관 시간**을 표시합니다. 적용한 그림 원본과 레이어, 키워드, 이펙트, 내 카드 서식도 함께 보관합니다. 그림·이펙트 편집 창에서는 **카드에 적용** 등으로 확정한 내용이 대상입니다. 자동 임시 보관은 폴더의 원본 JSON을 덮어쓰거나 **저장됨** 표시를 바꾸지 않습니다.

새 변경이 생기면 **자동 복구 대기**로 돌아가고, 최신 변경의 보관이 끝난 뒤에만 완료 시간을 표시합니다. 이전 변경의 늦은 저장 완료가 최신 작업의 완료 표시를 대신하지 않습니다.

다시 열면 이전 작업 안내와 상단 **작업 복구**에서 덱·시간·카드 수를 보고 복구할 수 있습니다. 현재 미저장 내용이 있으면 저장·버리기·취소를 먼저 고릅니다. 복구한 덱은 **미저장** 상태로 열리므로 **저장**을 눌러 파일에 보관하세요. 새 덱과 서로 다른 창의 작업은 별도 복구본으로 보관하고, 불필요한 복구본만 골라 삭제할 수 있습니다. 이 임시 자료는 같은 브라우저의 저장소에 있으므로 브라우저 데이터 삭제 후에는 JSON 파일 백업을 사용하세요.

## 카드 찾기와 인쇄 수량 일괄 변경

왼쪽 카드 목록에서 이름 검색과 **종류 / 등급 / 속성** 필터를 함께 사용합니다. 멀티 속성은 포함된 속성 중 하나로 검색하며, **속성 없는 아이템**과 **무속성**은 구별합니다. 필터는 카드 데이터를 숨기거나 인쇄 수량을 바꾸지 않습니다.

카드 왼쪽 체크박스는 일괄 변경할 카드를 고르고, 카드 이름은 편집할 카드를 엽니다. **Shift+체크**로 표시 중인 카드 범위를 선택하거나 **보이는 카드 선택 / 선택 해제**를 사용하세요. 수량을 입력하고 **수량 적용**을 누르면 선택한 카드만 한 번에 바뀌며 실행 취소 한 번으로 돌아옵니다. 필터에서 숨겨지거나 삭제된 카드는 선택에서 빠집니다.

## 내 카드 서식

상단 **내 카드 서식**에서 현재 카드의 배치·글자 설정·프레임 이펙트·독립 장식을 이름 붙여 저장합니다. 같은 종류의 다른 카드에 적용하면 카드 이름·HP·스킬 내용·대표 그림·속성·수량·Variant 연결을 유지하며 디자인을 바꿉니다. 다른 카드 크기에는 배치를 비례 조절하고, 기술은 같은 종류와 순서로 연결합니다. 대상 카드에 더 있는 기술도 유지합니다.

같은 서식 이름은 **덮어쓰기 / 추가 / 취소**를 고르며 이름 변경·삭제·적용을 실행 취소할 수 있습니다. 원본 카드가 없어져도 저장한 서식은 유지됩니다. 서식은 현재 덱의 JSON과 함께 저장·내보내기·복구되므로 다른 덱에서 쓰려면 서식이 포함된 프로젝트를 가져오세요.

## 이미지 자르기와 공용 에셋 보관함

상단 **에셋 보관함**에서 여러 그림을 가져오고, 이름 검색·이름 변경·삭제·PNG 다운로드·원본 다운로드를 사용할 수 있습니다. 보관함은 덱을 바꿔도 유지됩니다. **카드 그림으로 사용 / 새 이미지 요소로 추가**, 카드의 **보관함에서 가져오기**, 이펙트 입자와 키워드 아이콘의 **보관함에서 선택**으로 꺼내 쓰세요. 적용한 그림은 각 덱에 독립 복사하므로 보관함에서 삭제해도 카드와 이펙트는 유지됩니다.

**이미지 자르기**에서 그림을 드래그하거나 X/Y/너비/높이를 원본 픽셀로 입력합니다. 여러 영역은 목록에 추가해 한꺼번에 저장할 수 있습니다. **스프라이트 시트**는 행·열, 셀 크기, 시작 위치, 셀 사이 간격을 정하고 사용할 칸만 고릅니다. 확대·스크롤은 보기만 바꾸며, 조각은 원본 해상도와 투명도를 보존한 PNG가 됩니다. 카드 그림에서 한 조각을 자르면 새 그림으로 적용하며, 여러 조각은 보관함에 저장해 골라 사용합니다. 그림 작업실의 원본과 레이어는 유지됩니다.

**사람·물체만 자동으로 남기기**는 사진의 배경을 투명하게 만듭니다. 처음에 약 16MB의 처리 도구를 내려받아 브라우저에 보관하고, 이후 같은 브라우저에서는 오프라인으로 처리합니다. 그림을 서버에 보내지 않습니다. 결과를 확인하고 자를 영역을 정한 뒤 PNG로 저장하세요. **원본 배경으로 복원**으로 돌아갈 수 있고, 적용 전에는 원본을 바꾸지 않습니다. 스프라이트 시트에서는 배경 제거를 전체 시트에 적용한 뒤 선택한 조각을 저장합니다.

연결한 저장 폴더에서는 `작업실 데이터/에셋/asset-library.json`에 보관합니다. 폴더가 없으면 같은 브라우저에 임시 보관하며 상태와 위치를 표시합니다. 폴더 저장 실패나 외부 변경 충돌은 구체적으로 안내하고 **저장 재시도 / 다시 불러오기 / 보관함 JSON 내보내기**로 처리합니다. 저장하지 못한 초안은 다시 열어도 복구하며, 원래 폴더와 외부 변경 여부를 확인한 뒤 저장합니다. **다시 불러오기**로 초안을 버릴 때는 먼저 확인합니다. 임시 보관은 폴더 저장 완료를 뜻하지 않습니다. 다른 컴퓨터로 옮길 때는 보관함 JSON을 내보내서 가져오세요. 기존 데이터 폴더 내부에서는 새 데이터 폴더를 중첩 생성하지 않습니다.

## 오브젝트 목록과 잠금

오른쪽 **요소 찾기**에서 카드의 요소를 이름과 종류로 검색합니다. 목록 위쪽이 카드의 앞쪽입니다. 항목 클릭으로 선택하고 **Shift+클릭**으로 더하거나 해제합니다. 항목을 위아래로 끌거나 **↑ / ↓** 버튼으로 앞뒤 순서를 바꾸며 실행 취소할 수 있습니다.

**잠금**을 켜면 카드 화면에서 클릭·드래그·사각형 선택·크기 조절의 대상에서 빠집니다. 목록에서는 계속 선택해 글자나 위치를 수정하고 잠금을 풀 수 있습니다. 잠금은 마우스 조작을 막는 설정이며, 인스펙터·방향키·삭제 같은 명시적 편집은 사용할 수 있습니다. 여러 요소를 끌면 잠금이 풀린 요소만 움직입니다. 기술 내용이 길어져 자동 재배치되어도 잠금은 유지됩니다.

## 선택 대상만 이펙트 재생

이펙트 작업실의 **선택 대상만 재생**은 기본으로 켜져 있습니다. 현재 편집 대상을 움직이고 다른 대상은 저장할 인쇄 장면에 멈춥니다. 스킬 이름을 선택하면 그 이름의 제목과 설명 속 표시도 함께 움직입니다. 체크를 끄면 전체 효과를 함께 재생합니다. 이 보기 설정은 카드 JSON이나 실행 취소 기록을 바꾸지 않으며, 인쇄는 모든 효과를 정한 장면에 고정합니다.

멈춘 효과는 계산한 이미지를 재사용합니다. **Bloom · 밝은 빛 번짐**에 더해 색수차의 RGB 분리·외곽선·침식·안쪽 발광·안쪽 그림자·베벨·입체 두께·금박·홀로그램·글리치·주사선·입자 질감·두 색조·색 조절·포스터·하프톤·방향성 흐림·교차 일렁임, 윤곽 파동과 필터 합성도 지원 환경에서 GPU로 계산합니다. 실제 계산한 미리보기에는 **이펙트 GPU**, 블룸에는 **블룸 GPU**가 표시됩니다. 두 경로를 함께 쓴 프레임은 **GPU + CPU**, 멈춘 이미지만 재사용한 프레임은 해당 계산 표시를 생략합니다.

불꽃·연기·이미지 입자·글자 변형·기본 흐림·발광·그림자·그라데이션·혼합은 브라우저가 GPU를 사용할 수 있는 캔버스로 그립니다. 반투명 가장자리 모양을 유지하기 위해 색수차의 자동 어두운 글자·컬러 프린지도 이 경로를 사용합니다. 실제 하드웨어 사용 여부는 브라우저가 결정하므로 이를 WebGL 계산으로 세지 않습니다. 모양 분석·배치·파일 변환 등은 CPU에 남습니다. GPU 미지원·연결 손실·메모리 한도 초과 작업은 기존 방식으로 계속 그리며 연결 복구 후 GPU를 다시 사용합니다. 첫 처리와 크기 전환에는 준비 시간이 들고, 작은 효과는 전송 비용 때문에 더 느릴 수도 있습니다. 카드 JSON과 원본 그림은 유지합니다.

새 **독립 이펙트**는 **발생 위치 → 영역 전체**로 시작하며, **모양 안쪽 / 가장자리** 등으로 바꿀 수 있습니다. 기존 저장 조합의 발생 위치는 유지합니다.

재생·드래그 중에는 처리 속도에 따라 미리보기 해상도를 조절합니다. 멈추거나 조작을 끝내면 현재 확대 배율에 맞춰 선명하게 다시 그립니다. 작은 글자의 픽셀 필터는 필요한 영역만 전송하고 완전 교체 필터의 중복 합성을 생략합니다. 이 조절은 저장 데이터와 인쇄 해상도를 바꾸지 않습니다.

## 모바일 사용

좁은 화면에서는 상단 **카드 목록 / 편집 / 미리보기**로 작업 영역을 전환합니다. **저장 / 보관함**은 바로 누를 수 있고, **작업 메뉴**에서 불러오기·인쇄 등을 엽니다. 보관함은 전체 화면으로 열립니다. 자료를 눌러 상세 화면으로 들어갔다가 **목록으로** 돌아오면 검색·종류와 보던 위치가 유지됩니다. 카드·그림·이펙트 화면에서 두 손가락을 벌리거나 오므려 확대하고 함께 움직여 화면을 이동합니다. 손가락 하나는 기존 선택·그리기·이동에 사용합니다. 그림과 이펙트 편집창도 미리보기와 설정을 전환할 수 있습니다. 폴더 접근을 지원하지 않는 브라우저의 **저장**은 JSON 파일을 내려받으며 **불러오기**로 다시 엽니다.

## 저장 폴더와 카드 한 장 파일

```text
HTML이 있는 폴더/
  card-print-studio.html
  작업실 데이터/
    프로젝트/나의 카드 덱.card-project.json
    카드/새 몬스터.card.json
```

**저장 폴더**는 기억한 위치와 **기억한 폴더 다시 연결 / 다른 폴더 선택**을 보여 줍니다. 다음에 열 때 권한이 유지되어 있으면 바로 연결하고, 권한이 만료되면 기억한 폴더에 다시 허용하므로 매번 폴더 선택창에서 찾을 필요가 없습니다. HTML 다운로드 파일 이름이 바뀌어도 같은 브라우저의 연결 위치를 사용합니다.

HTML이 있는 폴더를 고르면 그 안에 `작업실 데이터/프로젝트`, `작업실 데이터/카드`를 만듭니다. `작업실 데이터` 자체를 고르면 그 폴더를 바로 사용합니다. `프로젝트` 또는 `카드` 폴더를 고르면 해당 파일을 그 안에 직접 저장하며, 다른 종류를 저장하려면 상위 데이터 폴더를 선택하도록 안내합니다. 위치를 구분할 수 없는 폴더는 직접 저장 위치로 사용합니다. 데이터 안쪽에 또 `작업실 데이터`를 만들지 않습니다.

**다른 폴더 선택**으로 연결 위치를 바꿉니다. 연결할 때 현재 덱을 덮어쓰거나 다른 덱을 자동으로 열지 않습니다. 새 덱과 JSON 가져오기는 새 파일로 저장되며, 기존 덱을 열어 수정하면 그 파일에 저장합니다. 덱 이름을 바꿔도 연결한 파일 이름은 유지됩니다. 다른 창에서 파일이 바뀌면 다시 불러와 확인하도록 안내합니다. 저장 중 편집·실행 취소한 내용은 실제로 저장한 시점과 구분해 표시합니다.

**JSON 내보내기 / JSON 가져오기**는 덱 전체의 휴대용 백업입니다. 폴더에 연결한 상태에서 백업을 내려받아도 폴더의 미저장 표시는 유지됩니다. 폴더 접근을 지원하지 않는 브라우저에서는 이 방법을 쓰거나 HTML을 Edge/Chrome에서 여세요. 연결을 기억해도 다음 실행에서 브라우저가 권한을 다시 요청할 수 있습니다. [폴더 접근 안내](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)

카드 목록 아래 **카드만 저장**은 선택한 한 장과 필요한 키워드·아이콘·그림 원본·레이어·이펙트를 `작업실 데이터/카드`에 별도 파일로 보관합니다. 같은 이름이 있으면 **덮어쓰기 / 추가 / 취소**를 고릅니다. 덮어쓸 파일이 여러 개면 목록에서 선택한 하나만 바꾸며, 추가는 새 파일을 만듭니다. 저장 중 다른 창에서 파일이 바뀌면 덮어쓰지 않고 알려 줍니다. 카드만 저장해도 덱 전체를 저장한 것으로 표시하지 않습니다. **카드 불러오기 → 카드 파일 가져오기**로 한 장의 JSON 파일을 직접 선택하세요. **저장 폴더 선택**은 폴더에 보관한 카드 목록을 엽니다. 창의 **선택 카드 파일 내보내기**로 `.card.json` 파일을 교환할 수도 있습니다. 파일 가져오기는 폴더 연결 없이 바로 쓸 수 있고, 폴더 선택 취소나 권한 거부 후에도 이용할 수 있습니다.

카드 불러오기·직접 파일 가져오기·JSON 드래그에서도 현재 덱에 같은 이름이 있으면 **덮어쓰기 / 추가 / 취소**를 고릅니다. 이름 앞뒤 공백과 한글의 같은 표기 형태는 동일하게 비교합니다. 덮어쓰기는 선택한 카드의 위치와 ID를 유지하고 내용을 바꿉니다. 연결된 Variant는 새 원본을 따르며 따로 바꾼 항목은 유지합니다. **추가**는 기존 카드를 남기고 새 ID를 붙입니다. 두 방식 모두 카드 실행 취소 한 번으로 되돌릴 수 있습니다. 경고 무시를 켜도 중복 선택은 그대로 물어봅니다.

불러온 카드의 내부 참조는 새로 붙이고, 가져온 Variant는 현재 내용을 가진 독립 카드가 됩니다. 읽는 도중 덱을 바꾸면 이전 불러오기는 반영하지 않습니다. 카드 크기는 현재 덱에 맞춰 위치·크기를 비례 조정하며 글자 크기·능력치는 유지합니다. 인쇄 장면은 현재 덱의 설정을 사용합니다. 같은 이름의 키워드가 이미 있으면 정의·색·아이콘이 같을 때 공유합니다. 내용이 다르면 이름을 구분하도록 안내하며 현재 작업을 유지합니다.

JSON 파일을 작업실 화면에 **끌어다 놓아도** 불러올 수 있습니다. 파일 내용으로 덱과 카드 한 장을 구분합니다. 덱은 현재 프로젝트를 바꾸고 카드 한 장은 현재 덱에 가져옵니다. 같은 이름의 카드는 위 중복 선택을 사용합니다. 덱에 저장하지 않은 변경이 있으면 기존 저장·버리기·취소 선택을 사용합니다. 한 번에 파일 하나를 놓으세요. 그림·이펙트 등 편집 창을 열어 둔 동안은 닫은 뒤 가져옵니다. 잘못된 파일은 현재 작업을 바꾸지 않으며, 폴더 연결도 자동으로 요청하지 않습니다.

## 카드 만들기

- 몬스터 또는 아이템을 추가하고 카드 이름과 인쇄 수량을 입력합니다.
- 몬스터 등급 C/B/A/S의 초기 HP 기준은 100/220/340/460입니다. 등급만 변경하면 현재 HP는 유지됩니다. **등급 기준값 적용**을 눌러 기준 HP를 반영합니다.
- **직접 깎을 HP**를 사용자가 정합니다. 최종 HP는 기본 HP에서 차감량을 뺀 값입니다. 기술을 추가하거나 바꿔도 차감량은 바뀌지 않습니다.
- 몬스터는 물/불/풀/무속성/어둠/빛을 여러 개 선택할 수 있습니다. 선택한 속성마다 기존 원 테두리 안에 그림을 표시하며, 무속성은 안쪽에 흰 원을 하나 더 그립니다. 기존 단일 속성 몬스터도 불러옵니다. 아이템은 기본 속성이 없지만 원 안의 양초 표시는 항상 유지합니다. 필요하면 같은 목록에서 0~6개 속성을 따로 부여하고, 모두 해제하면 속성 없는 아이템으로 돌아갑니다. ‘속성 없음’과 ‘무속성’은 다릅니다. 상성 계산은 하지 않습니다.
- 패시브와 액티브를 여러 개 추가하고 이름·효과·대미지를 직접 작성합니다. 각 기술 이름 바로 밑에 효과 설명을 놓고, 키워드 배지는 설명 뒤에 배치합니다. 별도의 공격력 스탯이나 강제 평타 기술은 없습니다.
- 기술의 **6면 주사위 조건**을 켜고 성공하는 눈과 문구·색을 정합니다. 1~6을 **가로 2칸 × 세로 3칸**의 작은 박스에 모으고 선택한 눈을 색으로 강조합니다. 판정 문구는 박스 옆에 표시합니다.

이름은 왼쪽 위, HP는 이름 옆, 속성과 등급은 오른쪽 위에서 시작합니다. 요소를 클릭해 이동하거나 모서리로 크기를 조절하고, 오른쪽에서 mm 위치·크기·글자·색·정렬을 바꿀 수 있습니다. 텍스트·이미지·사각형·주사위 요소도 추가할 수 있습니다.

일반 카드 화면에서도 **Ctrl+휠**로 마우스 위치를 중심으로 확대·축소합니다. 하단 **− / ＋**, 배율 슬라이더, **100% / 맞춤**도 이용할 수 있으며 범위는 **25~800%**입니다. **맞춤**은 카드 전체를 화면의 가로·세로에 맞춥니다. **A4 용지 보기**에서도 Ctrl+휠과 기존 배율 입력·맞춤·화면 자 보정을 이용합니다. 일반 휠은 스크롤합니다. 확대와 디스플레이 해상도에 맞춰 다시 그리며, 계산 한도를 넘으면 픽셀 경계를 선명하게 표시합니다. 화면 배율은 카드 데이터·실행 취소 기록·실제 인쇄 치수에 저장하지 않습니다.

**기술 영역 자동 맞춤**은 패시브·액티브 설명을 영역 폭에 맞춰 줄바꿈하고, 긴 기술에 더 많은 높이를 줍니다. 뒤의 기술과 키워드·주사위 영역도 함께 배치합니다. 내용을 수정하면 현재 그림 영역과 직접 정한 글자 설정을 보존하고 기술 높이를 다시 계산합니다. 기술의 위치·크기를 직접 바꾸면 자동 맞춤이 꺼져 자유 배치를 유지하며, 글자 설정 변경은 자동 배치에 반영합니다. 체크를 다시 켜거나 **긴 효과 맞춤**을 누르면 기술 영역을 다시 배분합니다. 글자가 넘치거나 기술의 표시 요소를 삭제하면 안내가 나타나며 바로 인쇄와 PDF 출력은 그대로 진행할 수 있습니다. 미리보기에서 보이는 잘림과 누락을 그대로 출력합니다.

## Variant 만들기

원본 카드를 선택하고 오른쪽 **+ Variant 만들기**를 누르면 하위 카드나 스페셜 카드를 만듭니다. 새 Variant는 원본과 연결되고, 인쇄 수량은 1장으로 시작합니다.

- 이름·속성·체력·기술·그림·배치는 원본을 공유합니다. Variant에서 직접 바꾼 부분만 따로 유지합니다. 효과만 바꾸면 기술 이름과 다른 효과는 계속 원본을 따릅니다. 원본에 새 기술을 추가하면 Variant에도 들어옵니다.
- **Variant 구분명**은 카드 목록에 표시하는 이름입니다. 카드에 인쇄할 이름은 일반 **카드 이름**에서 바꿉니다.
- 각 카드의 **인쇄 수량**을 직접 정합니다. 목록과 인쇄에는 원본과 연결된 Variant가 이어서 배치되며, 지정한 수량만 출력합니다.
- **원본: 카드 이름** 버튼으로 원본을 엽니다. 변경 항목의 **원본 값으로** 또는 **변경 모두 원본 값으로**를 눌러 공유를 복원합니다.
- **연결 해제 · 독립 카드로**는 현재 내용을 유지한 채 연결을 끊습니다. 원본을 삭제해도 연결된 Variant는 현재 내용과 수량을 보존한 독립 카드로 남습니다. 일반 **복제**도 독립 카드를 만듭니다.
- 원본의 주사위 조건을 끄면 상속한 조건도 숨깁니다. Variant에서 따로 바꾼 문구는 다시 켰을 때 복원됩니다. 조건이 없던 Variant에 직접 추가한 주사위 조건은 별도로 유지합니다.
- 공유 관계와 변경 내용은 프로젝트 저장·불러오기, 실행 취소·다시 실행에 포함됩니다.

## 키워드 만들기

상단 **키워드 관리 → 키워드 추가**에서 이름·설명·색을 정하고 PNG/JPEG/WebP 아이콘을 가져옵니다. 이름은 비워 두거나 중복해서 만들 수 없습니다. 아이콘 없이 이름과 색만 사용해도 됩니다.

**전용 이펙트 만들기 / 수정**에서 키워드마다 효과를 조합하세요. 제목·본문에 같은 이름을 직접 입력해도 적용되고, 연결한 배지의 글자에도 함께 적용됩니다. 긴 이름이 겹치면 긴 키워드를 먼저 인식합니다. 아직 카드에서 쓰지 않는 키워드는 이름 샘플로 미리 볼 수 있습니다. 선택한 글자에 따로 지정한 설정이 우선하며 기존 스킬의 글꼴 크기·기울임은 유지합니다. 효과를 지워도 키워드 색은 유지됩니다. 실행 취소·프로젝트와 카드 한 장 저장·클라우드 공유에는 효과와 사용한 입자 그림도 함께 포함됩니다.

- 패시브·액티브 또는 아이템 효과의 **키워드 선택**에서 원하는 키워드를 고릅니다.
- 카드 이름(몬스터·아이템)과 패시브·액티브 제목은 등록된 키워드를 **직접 입력하면 색·굵기·아이콘을 자동으로 표시**합니다. 제목을 먼저 작성하고 키워드를 나중에 등록해도 반영됩니다. 이름이 겹치면 더 긴 키워드를 먼저 찾아 표시합니다.
- 제목 아래 **제목 키워드 · 자동 표시**에서 적용 중인 키워드를 볼 수 있습니다. **제목에 넣기**는 현재 커서 위치에 삽입하는 편의 기능이며 직접 입력할 때는 누르지 않아도 됩니다. 제목에서 해당 글자를 지우거나 키워드를 삭제하면 자동 표시도 사라집니다.
- **본문에 넣기**는 현재 글자 선택 위치에 이름을 넣고 본문 강조로 연결합니다. 이미 적은 이름을 강조하려면 배지를 추가한 뒤 표시 방식을 바꿀 수도 있습니다.
- **배지 추가**는 기술 효과 설명 아래에 이름과 아이콘이 있는 배지를 넣습니다. 아이템은 효과 영역에 배치합니다. 각 연결의 **카드 표시**에서 본문 강조 / 배지 / 본문 강조 + 배지를 선택합니다.
- 제목과 본문에 등록된 키워드 이름을 입력하면 색·굵기·아이콘으로 강조합니다. 등록한 설명은 편집창에서 확인하고, 카드에 인쇄할 설명은 효과 본문에 작성합니다.
- 관리창에서 이름을 변경하면 연결된 본문과 배지가 함께 바뀝니다. 색과 아이콘도 모든 연결에 반영됩니다.
- 연결 해제는 해당 배지를 제거합니다. 직접 입력한 이름의 자동 강조는 키워드가 등록되어 있는 동안 유지됩니다. 키워드를 삭제하면 강조가 사라지고 작성한 글은 유지됩니다. 카드 실행 취소로 복원할 수 있습니다.
- 키워드 정의, 기술별 표시 방식, 아이콘 원본도 프로젝트 파일에 함께 저장됩니다. 이전 버전 1 파일은 키워드 없이 불러올 수 있으며, 직접 배치한 카드의 위치와 그림 원본을 유지합니다.

오른쪽 아래 **덱 설정**에서 카드 치수, 카드 한 장의 최대 치수, 최소 글자 크기, 등급별 HP 기준과 선택적 상한을 바꿉니다. 초기값은 카드와 최대 치수 모두 **63 × 88 mm**, 최소 글자 **7 pt**입니다. 모든 앞면과 공통 뒷면의 크기가 함께 바뀝니다. 최대값을 줄이면 필요한 카드 축소를 확인합니다.

**공통 뒷면**에서 전체 덱에 사용할 뒷면을 편집하세요.

## 다른 스킬 이름을 본문에 넣기

패시브·액티브의 효과 설명에서 넣을 위치를 누르고, 아래 **스킬 참조 → 이 카드의 다른 스킬 선택 → 스킬 이름 넣기**를 사용합니다. 현재 카드의 다른 패시브·액티브에서 고르며, 같은 이름도 종류와 순번으로 구분합니다. 카드에는 파란 굵은 글자와 얇은 밑줄로 강조됩니다.

참조한 스킬의 이름을 바꾸면 본문의 표시와 줄바꿈도 갱신됩니다. 참조 앞뒤 문장을 편집하면 연결을 유지하고, 강조된 이름 자체를 고치거나 **×**를 누르면 그 부분의 연결을 해제합니다. 표시된 이름은 일반 문장으로 남습니다. 대상 스킬을 삭제해도 작성한 본문은 지우지 않으며, 참조 목록에서 누락된 대상을 안내합니다. 프로젝트 저장·불러오기·카드 복제와 Variant에서도 연결을 보존합니다. Variant에서 본문을 직접 바꾸면 본문과 그 안의 참조 위치를 함께 별도로 보관합니다.

## 스킬 이름만 꾸미기

각 패시브·액티브의 **스킬 이름만 이펙트**를 누르세요. 창 위쪽의 **이름만 · 스킬명** 대상과 같습니다. **글자 색**을 고르고 불꽃·발광·외곽선·왜곡 등을 조합하면 제목의 실제 이름과 설명 속 같은 이름에 함께 적용됩니다. ‘패시브 · / 액티브 ·’ 접두어와 나머지 설명은 유지됩니다. 연결해서 넣은 참조와 직접 입력한 동일한 이름을 모두 표시합니다. 직접 입력한 이름은 이름 변경 시 자동으로 바뀌지 않습니다.

긴 이름을 먼저 매칭하며, 동명 스킬이 여럿이면 직접 입력한 이름은 카드 순서의 첫 스타일을 사용합니다. 명시적으로 넣은 스킬 참조는 선택한 스킬의 스타일을 따릅니다. 이름 전용 스타일은 제목 전체의 이펙트와 따로 보관합니다. 일반 글자 대상에서도 이펙트 창의 **글자 색**을 바꿀 수 있습니다. **기본 글자 색 사용**으로 색만 되돌리고 이펙트는 유지합니다. 대상 전환은 편집 내용을 유지하고 **적용** 한 번으로 반영합니다. 닫기에서 변경을 버리면 색도 함께 취소됩니다.

참조할 이름을 고른 뒤 다른 입력란을 편집해도 효과 설명의 커서·선택 범위를 기억합니다. **스킬 이름 넣기**는 기억한 위치에 넣거나 선택한 글자를 대체합니다. 선택한 이름도 입력 중 창 갱신에서 유지됩니다.

이펙트 제작기의 각 생성·필터 레이어에서도 **혼합 모드** 26종을 선택합니다. 앞/뒤 배치 순서에 따라 나중에 얹는 그림을 혼합하며, 필터의 일반 모드는 기존 효과량 조절을 유지합니다. 좌표만 바꾸는 글자 형태 왜곡에는 색 혼합 설정이 없습니다. 모드는 내 이펙트·Variant·실행 취소·인쇄 장면에 함께 보관됩니다.

## 글자와 자동 배치

글자 크기·굵기·기울임·자간·줄간격·정렬·밑줄을 따로 조절합니다. 카드 이름, 기술 제목과 효과 설명, 자유 글자를 각각 꾸밀 수 있고 이펙트 창에서도 선택한 글자의 설정을 바꿉니다. **이름만** 대상의 설정은 실제 스킬 이름과 설명 속 같은 이름에 적용합니다.

**기술 영역 자동 맞춤**을 켜면 줄바꿈한 내용과 글자 설정에 맞춰 기술 높이를 정하고 다음 기술을 아래에 배치합니다. 글자 크기를 바꿔도 자동 배치를 유지하며, 설명을 줄이면 뒤의 기술도 올라옵니다. 직접 배치한 그림과 자유 요소의 위치는 보존합니다. 기술 영역을 수동으로 옮기거나 크기를 정하면 수동 배치를 사용합니다.

선택한 카드 요소는 방향키로 **1px**, Shift+방향키로 **10px** 이동합니다. 인쇄용 300dpi의 픽셀을 기준으로 하므로 화면 배율을 바꿔도 이동량은 같습니다. 정렬 기준을 카드 전체 또는 선택한 요소 범위에서 고르고 좌우·상하·가운데에 맞춥니다. 세 개 이상을 선택하면 가로·세로 간격도 맞출 수 있습니다. 이동과 정렬은 카드 실행 취소로 복원합니다.

글자 넘침·작은 글자·카드 밖으로 나간 내용 등의 안내가 있어도 **바로 인쇄 / PDF 만들기**를 진행합니다. 영역에 잘린 부분을 포함해 현재 렌더된 모습 그대로 출력합니다. 상단 **경고 무시**를 켜면 카드 편집과 이펙트 제작기의 출력·배치 경고를 숨깁니다. 끄면 다시 표시하며 설정은 이 브라우저에 기억합니다. 글자·그림·인쇄 결과와 저장할 카드 내용은 바꾸지 않습니다. 잘못된 파일·저장 실패·인쇄 오류는 계속 표시합니다.

## 직접 그림 그리기

**그림 가져오기**로 PNG/JPEG/WebP 원본을 넣거나 **그림 그리기**를 누릅니다. 처음 빈 그림은 1200 × 1200 px, 투명 레이어 한 장입니다. 기존 레이어가 있으면 그대로 다시 열립니다. 직접 가져온 그림은 첫 레이어가 됩니다.

새 카드의 그림은 비율을 유지해 영역 안에 전체가 보이도록 자동 맞춥니다. 기존 카드도 **그림 자동 맞춤**으로 바꿀 수 있습니다. 투명한 부분은 카드에서도 투명하게 표시됩니다. 그림 요소의 **투명 배경 유지**를 끄면 배경색을 직접 정할 수 있습니다. **그림 맞춤 → 영역 채우기**와 자르기 위치는 수동 조절용으로 사용할 수 있습니다.

- 브러시와 투명 지우개, 브러시 크기 0.1~4096 px, 색·불투명도·경도·선 보정, 픽셀 맞춤을 지원합니다.
- 실제 펜의 압력으로 브러시 크기를 바꾸는 옵션이 있습니다. 마우스는 일정한 크기로 그립니다.
- **브러시 프리셋**은 펜·연필·마커·에어브러시·픽셀 펜 5종입니다. 고른 뒤 원형/사각 붓, 크기·경도·불투명도·선 보정을 직접 조절합니다. 픽셀 펜은 1px 사각 붓과 픽셀 맞춤으로 시작합니다.
- **좌우 대칭 / 상하 대칭**을 켜면 브러시·지우개의 반대편도 함께 그립니다. 둘 다 켜면 네 방향이며, 중앙이 겹쳐도 같은 획을 중복해서 진하게 만들지 않습니다. 한 획은 그림 실행 취소 한 단계입니다.
- **그려진 곳에만 칠하기**는 투명한 바깥에 색을 늘리지 않고 현재 레이어의 색을 바꿉니다. 옅은 선의 원래 투명도도 유지하며 지우개에는 적용하지 않습니다.
- 채우기의 **보이는 모든 레이어를 기준으로 채우기**를 켜면 별도 선화 레이어를 경계로 삼아 현재 채색 레이어에만 칠합니다. 끄면 현재 레이어의 연속 영역을 채웁니다. 허용차를 조절할 수 있고 잠긴 레이어·선택 영역을 존중합니다.
- **그라데이션(D)**은 시작 색과 끝 색을 정하고 캔버스를 끌어 직선/원형으로 채웁니다. 선택 영역·불투명도·그려진 곳 보호를 반영하며 확정 전 미리보기와 Esc 취소, 실행 취소를 지원합니다.
- 스포이트는 표시된 레이어의 합성색을 읽습니다. 직선·사각형·타원과 도형 안쪽 채우기도 지원합니다.
- 레이어를 추가·복제·삭제·이름 변경하고, 목록에서 마우스로 끌어 순서를 바꿉니다. 삽입선을 보고 놓으세요. 바깥에 놓거나 Esc를 누르면 이동을 취소하며, 기존 위로/아래로 버튼도 사용할 수 있습니다. 표시·잠금·불투명도와 **레이어 혼합 모드**를 바꿀 수 있습니다.
- 혼합 모드는 일반·곱하기·스크린·오버레이·어둡게·밝게·색상 닷지/번·하드/소프트 라이트·차이·제외·색조·채도·색상·광도·더하기와 겹침/지우기 등 26종입니다. 투명 바탕에서 레이어를 합성한 결과를 미리보기·PNG·카드에 동일하게 사용하고, 흰 PNG는 그 뒤에 흰 배경을 깝니다. 모드와 순서는 그림 실행 취소 및 프로젝트·카드 파일에 보관합니다.
- **아래 레이어와 합치기**는 현재 그림의 픽셀이 유지될 때 적용합니다. 아래 배경에 의존하는 혼합 때문에 그림이 달라지는 경우에는 이유를 안내하고 원본과 기록을 유지합니다. 최소 한 레이어는 유지됩니다.
- 사각 선택은 현재 레이어에 적용됩니다. 선택 안에만 그리거나 지우고, 내부 복사·잘라내기·붙여넣기를 할 수 있습니다. 선택을 끌어 이동하고 모서리로 크기를 바꾸거나 X/Y/가로/세로를 입력하세요. 좌우·상하 반전과 90도 회전도 가능합니다. **변형 확정 / 취소**를 누릅니다. 변형 미리보기 중 복사·잘라내기는 먼저 확정 또는 취소하도록 안내합니다. 전체 선택 버튼이나 Ctrl+A로 캔버스 전체를 정확히 선택합니다. 캔버스 밖으로 나간 부분은 적용 시 잘립니다.
- 휠은 커서를 중심으로 확대합니다. H 또는 Space를 누르고 끌어 화면을 옮깁니다. 12.5~1600% 배율, 전체 맞춤, 100%가 있습니다. 전체 맞춤은 큰 캔버스의 경우 12.5%보다 작아질 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| B / E / M / H | 브러시 / 지우개 / 선택 / 화면 이동 |
| G / D / I / L / R / O | 채우기 / 그라데이션 / 스포이트 / 직선 / 사각형 / 타원 |
| Ctrl+Z / Ctrl+Shift+Z | 그림 실행 취소 / 다시 실행 |
| Ctrl+A | 현재 레이어 전체 선택 |
| Ctrl+C / Ctrl+X / Ctrl+V | 선택 복사 / 잘라내기 / 내부 붙여넣기 |
| Enter / Esc | 선택 변형 확정 / 취소 |
| 방향키 / Shift+방향키 | 선택을 1 / 10 px 이동 |

글자를 입력하는 중에는 그림 단축키가 동작하지 않습니다. 그림 기록은 카드 기록과 별개로 최근 **40단계 또는 압축 자료 128 MiB**까지 보관합니다. 한 작업이 용량 한도를 넘으면 작업을 원복합니다.

작은 그림도 확대할 때 픽셀 경계를 선명하게 표시합니다. 픽셀 맞춤을 끈 부드러운 붓에도 확대 표시는 적용하며, 100% 미만에서는 축소에 맞는 보간을 사용합니다. 화면 표시만 바꾸므로 원본 크기·픽셀·PNG와 카드에 적용한 그림은 유지됩니다.

**캔버스 크기**는 각 변 64~4096 px입니다. **범위만 변경**은 픽셀 크기를 유지하며 9방향 기준점에 따라 여백·잘림을 바꿉니다. **그림도 리샘플**은 확인 후 그림 자체를 확대·축소합니다. 4096 px를 넘는 원본은 보존하며, 사용자가 선택한 경우에만 그리기용 레이어를 축소합니다.

**투명 PNG / 흰 배경 PNG**로 그림을 따로 내려받을 수 있습니다. **카드에 적용**하면 실제로 그린 부분의 바깥 투명 여백을 자동으로 잘라 카드에 넣습니다. 희미한 선과 그림 내부의 투명 공간도 보존합니다. 편집용 원본 캔버스 크기와 레이어는 **저장**으로 함께 보관하므로 다시 열어 계속 그릴 수 있습니다. 적용은 카드 실행 취소 한 단계입니다. 일반 복제 카드는 현재 카드에만 새 그림을 적용합니다. 원본의 그림 변경은 그림을 공유 중인 Variant에도 반영되며, Variant에서 그린 그림은 해당 Variant의 별도 그림으로 유지됩니다. 기존 그림 위치·크기·맞춤·자르기는 유지됩니다. 그림 전체를 보이려면 카드의 그림 요소를 선택하고 **그림 맞춤 → 전체 보이기**를 선택하세요.

닫기나 Esc로 나갈 때 변경이 있으면 **카드에 적용 / 그림 버리기 / 계속 그리기**를 선택합니다. 계속 그리기나 확인창의 Esc는 그린 내용을 유지합니다. 닫은 뒤 **그림 그리기**로 다시 열 수 있습니다. 선택 변형 중 Esc는 우선 변형을 취소합니다.

## 시각 이펙트 만들기

그림이나 글자를 선택하고 **선택한 대상 이펙트 만들기**를 누릅니다. 선택한 그림·글자가 바로 대상으로 열립니다. 창 위쪽 **효과를 붙일 대상**에서 카드 이름·HP·제목 전체·기술 설명·아이템 효과·자유 글자·그림으로 바꿀 수도 있습니다. 카드 테두리는 **프레임 이펙트 만들기**, 독립 장식은 **이펙트 요소 추가**를 사용합니다. 공통 뒷면의 그림·글자에도 적용할 수 있습니다.

입력칸에서 한 글자나 구간을 선택하고 **선택 글자 이펙트**를 누르면 그 부분만 색·글꼴·효과를 바꿉니다. 선택이 없으면 커서의 한 글자를 고릅니다. 이모지처럼 여러 문자로 이뤄진 한 글자도 함께 선택합니다. 제목·효과 설명·자유 글자에 사용할 수 있고, 스킬 이름에 적용하면 설명 속 같은 스킬 이름에도 이어집니다. 입력칸 아래에서 구간을 다시 편집하거나 해제합니다. **불타며 이글거리는 글자** 프리셋은 따뜻한 그라데이션·발광·불꽃·불티·열기 왜곡을 조합합니다. 저장·불러오기·실행 취소·Variant·인쇄에 글자 구간을 함께 보관합니다.

1. **프리셋 둘러보기**에서 실제 렌더 견본을 누릅니다. 이름 검색과 분류로 조합을 찾을 수 있습니다. 기존 불꽃·연기·번개·네온 외에 RGB 분리, 사이버 글리치, 푸른 홀로그램, 장미 금속, 은빛 크롬, 마법 황금, 얼음 수정, 용암 심장, 독성 슬라임, 그림자 부조, 잉크 도장, 레트로 인쇄, 비전 룬, 별빛 꿈결, **4각 별빛 반짝임**을 제공합니다. **다른 프리셋 겹치기**로 더하거나 빈 조합에서 시작합니다.
2. 오른쪽에서 레이어를 추가하고 색·크기·농도·개수·속도 등을 조절합니다. 동그란 불덩이와 질감 있는 연기가 글자·그림의 윤곽을 따라 피어납니다. 발생 면은 윗면·아랫면·옆면·모든 가장자리·안쪽·직접 정한 영역에서 고르고, **바로 앞이 빈 곳만**으로 좁은 틈의 발생을 줄입니다. 직접 정한 영역과 회전은 **고급**에서 조절합니다. 한 조합은 최대 **12개 레이어**, 불꽃은 최대 **260개**, 연기는 **200개**, 이미지·도형 입자는 **120개**, 기존 개별 입자는 **80개**입니다.
3. **원본** 아래에서 레이어를 위→아래 순서로 자유롭게 쌓습니다. 생성 효과는 지금까지의 결과 앞/뒤에 놓고, 필터는 그 시점까지 쌓인 결과를 바꿉니다. 예를 들어 **불꽃 → 픽셀화**는 불꽃까지 픽셀로 바꾸고, **픽셀화 → 불꽃**은 픽셀화된 글자에 부드러운 불꽃을 붙입니다. 외곽선·발광·그림자·그라데이션·빛 스윕 외에 픽셀화·흐림·색 조정·포스터화·하프톤 망점·색수차·물결 왜곡·가장자리 침식을 조합합니다. 필터 범위는 전체·원본 안쪽·원본 바깥에서 고릅니다.
4. 글자에는 **글자 형태 왜곡**을 하나 추가해 아치·물결·기울임·가로/세로 배율을 조절합니다. 왜곡은 맨 먼저 적용하고 이후 효과가 변형된 모양을 따릅니다. 문구와 키워드 연결은 유지하며 그라데이션·빛 스윕은 본문 안의 키워드·아이콘 구분 색을 보존합니다.
5. 창 위 **실행 취소 / 다시 실행**으로 적용 전 변경을 최근 100단계까지 되돌립니다. Ctrl+Z, Ctrl+Shift+Z 또는 Ctrl+Y도 지원하며 글자 입력 중에는 입력칸의 기본 실행 취소가 우선합니다. 대상 간 변경·글자 색·레이어 순서·고정 장면도 함께 복원합니다. 여러 대상을 오가며 각 조합을 편집한 뒤 **편집한 대상에 적용**을 누릅니다. 바꾼 대상들을 한꺼번에 반영하며, 실행 취소 한 번으로 되돌립니다. 닫기나 Esc에서 **계속 편집 / 변경 버리기**를 선택하며, 버리기는 카드에 적용하지 않은 조합과 임시 인쇄 시간을 취소합니다.

**글자 보호**는 기본으로 켜져 다른 글자 위의 효과를 줄입니다. 해당 레이어의 **글자 위에도 그리기**를 켜면 보호를 해제합니다. 자신에게 적용한 글자는 보호 대상에서 제외됩니다. 다른 글자를 많이 덮으면 출력 점검에서 안내합니다.

색수차의 **자동**은 검정·어두운 글자에 두 색의 테두리를 더하고, 밝은 컬러 그림에는 RGB 채널을 나눕니다. **RGB 채널 / 색 테두리**를 직접 선택하고 분리 거리·방향·두 색·강도를 조절할 수 있습니다. 검정 채널을 옮겨 검은 잔상이 생기던 동작을 수정했습니다.

**안쪽 발광·안쪽 그림자·양각/음각·두께/입체·금속 반사 무늬·무지개 분광 무늬·글리치·주사선·입자 질감·두 색조**를 자유롭게 조합합니다. 금속·홀로그램은 밝기와 색 띠로 표현하는 무늬이며 일반 프린터에서는 선택한 정지 장면의 색으로 인쇄됩니다. 실제 반사 코팅을 만들지는 않습니다.

**이미지·도형 입자**에서 별·원·룬·마름모·꽃잎·눈송이를 고르거나 직접 그린 PNG/JPEG/WebP를 가져옵니다. 별도로 나뉘던 룬·꽃잎 등 모양 효과는 새 추가 목록에서 이 항목으로 묶었습니다. 예전 카드와 프리셋의 개별 효과는 계속 편집하고 인쇄할 수 있습니다. 반딧불·기포·혜성·비·먼지·소용돌이처럼 움직임이 다른 효과도 함께 조합합니다.

**4각 별빛**은 [허블의 시리우스 사진](https://esahubble.org/images/heic0516a/)을 참고해 밝은 중심과 가는 네 방향 광선, 투명하게 사라지는 빛 번짐을 그립니다. 별 색·중심색·개수·크기·꼭짓점 폭·세로 비율·빛 번짐·반짝임·회전을 조절합니다. 같은 시간과 시드는 같은 모양이며 선택한 장면을 인쇄할 수 있습니다. 별마다 크기가 달라도 한 조합의 빛 이미지를 재사용합니다.

이미지를 여러 입자로 뿌리거나 **한 장 고정 배치**로 크게 놓을 수 있습니다. 좌우·상하 자르기를 백분율로 정하고, 가로·세로 배율·뒤집기·회전 중심을 독립 조절합니다. 자르기는 원본 그림을 바꾸지 않습니다. 시작/끝 크기 비율은 0~8로 지정합니다.

여러 컷이 들어 있는 이미지는 가로·세로 칸 수를 정해 재생합니다. 컷 번호는 왼쪽 위부터 **0번**이며 컷 수 **0**은 시작 컷부터 남은 전체를 사용합니다. 고정 컷·수명에 맞춤·반복·왕복과 초당 컷 수를 선택하고, 선택한 시각의 장면을 인쇄에 고정합니다. **소환마다 랜덤 한 컷**은 입자마다 다른 컷을 골라 유지하고, **랜덤 컷 계속 재생**은 설정한 속도로 컷을 바꿉니다. 시드와 시간을 고정하면 랜덤 컷도 같은 결과를 인쇄합니다. 입자 이미지 아래 **이미지 자르기·배경 제거 / 스프라이트 시트 자르기**로 바로 편집하고 선택한 칸을 투명 시트로 묶습니다.

이펙트 미리보기의 **드래그 변형**으로 선택한 이미지나 발생 영역을 옮기고 손잡이로 크기·회전을 조절합니다. 방향키 1px / Shift+방향키 10px와 대상 영역 기준 정렬도 지원합니다. 한 번의 조작은 실행 취소 한 단계이며 Esc나 포인터 취소는 조작 전 상태로 돌아갑니다.

시작/끝 크기, 시작/끝 투명도와 색, 나타남/사라짐 구간, 수명, 방향, 이동 거리, 흩어짐, 중력, 회전과 회전 속도를 조절합니다. 끝 크기가 작으면 줄어들고 0이면 사라집니다. **배치 변화 0**은 같은 경로를 반복합니다. 가져온 이미지의 비율·투명 공간을 유지하고 원래 색/한 색/수명에 따른 두 색을 고를 수 있습니다. 그림을 읽는 동안 적용·프리셋 저장은 잠시 기다립니다. 적용 전 이미지는 임시로 보관하며 **변경 버리기**로 취소됩니다. **내 이펙트로 저장**은 이미지까지 실제 저장하는 별도 작업입니다. 카드 한 장 파일에도 그 카드가 사용하는 입자 이미지가 함께 들어갑니다.

**Bloom · 밝은 빛 번짐**은 밝기 기준을 넘는 부분에서 빛을 퍼뜨립니다. 밝기 기준·경계 부드러움·반경·강도·색을 정하고 불꽃이나 밝은 글자 다음에 놓습니다. **방향 흐림**은 길이·방향·샘플 수·강도로 잔상을 만들고, **교차 일렁임**은 가로/세로 흔들림 거리와 간격으로 열기·수면 같은 움직임을 만듭니다. 새 **눈부신 빛 / 떠오르는 빛의 문양 / 빛의 잔상 / 수면의 신기루** 조합에서 시작할 수도 있습니다. 높은 해상도에 여러 흐림 효과와 많은 샘플을 겹치면 계산 시간이 늘어납니다.

**이글거림 · 열기 왜곡**은 뜨거운 공기처럼 불규칙하게 아른거리는 효과입니다. 세기·무늬 크기·세부 변화·방향과 재생 속도를 조절하세요. **이글거리는 열기** 조합이나 열기 왜곡을 포함한 **불타는 글자**에서 시작하고, 불꽃·발광을 더할 수 있습니다. GPU를 사용할 수 없으면 같은 무늬의 대체 렌더링으로 표시합니다. 움직임을 끄면 정지하며, 인쇄에는 고정한 장면을 사용합니다.

**외곽선은 원본과 입자의 투명도를 따릅니다.** 옅은 연기나 거의 사라진 파동에 진한 테두리가 남지 않습니다. **파동 → 외곽선** 순서로 쌓으면 파동의 끝과 테두리가 함께 사라집니다. 파동의 **끝 사라짐** 값이 클수록 더 빨리 옅어지고, 기존 파동은 같은 기본 곡선을 유지합니다. 시작보다 끝 크기를 작게 설정하면 파동이 수축하며, 끝 크기 0도 사용할 수 있습니다.

미리보기 위 **확대 50~800%**, **선택 대상 확대**로 작은 글자와 윤곽을 확인합니다. **Ctrl+휠**은 마우스 위치를 중심으로 확대·축소하고, 일반 휠은 스크롤합니다. 확대 배율과 화면 해상도에 맞춰 다시 그리며 최대 계산 해상도에서는 픽셀을 선명하게 표시합니다. **원본 비교 · 누르기**는 누르는 동안 선택 대상의 효과를 빼서 보여줍니다. 놓으면 효과가 돌아오며 확대·비교는 카드 크기나 저장 내용을 바꾸지 않습니다.

프레임 범위는 **테두리 / 테두리 + 안쪽 번짐 / 배경 전체**, 띠 두께는 **2~10mm**입니다. 효과는 다른 카드 요소 뒤에 그려지며 카드 실물 크기는 유지됩니다. **인쇄 품질로 보기**는 100%에서 300dpi로 확인하며 확대할 때는 계산 한도 안에서 해상도를 더 높입니다. 변경 후 잠시 **계산 중**이 표시되며 같은 설정과 시간의 배치는 유지됩니다.

**내 이펙트**에 이름을 붙여 **새 이펙트로 저장**하면 다른 카드에서 재사용할 수 있습니다. 저장본 수정·삭제는 이미 적용한 카드의 조합을 바꾸지 않습니다. 저장본과 카드 적용은 별도이므로 저장만 했다면 적용 버튼도 누르세요. 그림 원본 PNG와 편집용 그림 레이어는 그대로 보관합니다. 투명한 선화의 빈 부분에 배경을 추가하지 않습니다.

Variant는 이펙트도 원본과 공유합니다. Variant에서 바꾼 레이어 값만 독립적으로 유지하고, 다른 값은 원본의 후속 변경을 따릅니다. 템플릿 전환과 기술 자동 배치에서도 대응하는 기술의 효과와 독립 장식을 유지합니다.

### 움직임 확인과 인쇄 장면

미리보기는 처음에 멈춰 있습니다. **재생**하거나 시간 막대를 움직여 원하는 장면을 고른 뒤 **장면 고정 → 편집한 대상에 적용**을 누르세요. 6초에서 처음으로 돌아가지 않고 계속 재생하며 시간 막대도 자동으로 늘어납니다. 카드 편집 화면에서도 재생·시간 이동·인쇄 장면 지정을 할 수 있고, A4 설정의 **고정 인쇄 장면 (초)**에서 숫자로 지정할 수 있습니다.

제작기의 **인쇄 장면**으로 저장할 장면을 다시 확인합니다. 미리보기 재생만으로 프로젝트나 인쇄 장면이 변경되지는 않습니다. A4 보기·바로 인쇄·PDF는 항상 **프로젝트에 저장한 인쇄 시간**을 사용합니다. 같은 조합·배치·그림·시간은 같은 장면을 만들며 재생 중 바로 인쇄하거나 PDF를 만들어도 장면이 바뀌지 않습니다. A4 보기·숨긴 탭·창 닫기에서는 재생을 멈춥니다.

가장자리에서 장식이 잘려도 출력할 수 있습니다. 오류는 해당 카드·기술·필드, 현재 값과 허용 범위를 구체적으로 안내합니다. 글자 넘침이나 실제 최소 글자 크기 위반도 출력은 진행합니다. 예를 들어 7pt 글자를 세로 0.5배로 압축하면 3.5pt라는 안내를 표시하며, **경고 무시**로 숨길 수 있습니다. 보이는 그대로 인쇄합니다.

## 요소 여러 개 선택하기

카드 안이나 주변 빈 여백에서 사각형을 드래그하면 겹치는 요소들을 한꺼번에 선택합니다. 어느 방향으로 끌어도 됩니다. **Shift+클릭**은 요소를 추가하거나 해제하고, **Shift+빈 곳 드래그**는 기존 선택에 더합니다. 빈 곳을 클릭하거나 Esc로 선택을 해제합니다.

선택한 요소 위를 끌면 간격을 유지한 채 함께 움직이며 카드 경계에서 함께 멈춥니다. 방향키는 인쇄 300dpi 기준 1px, Shift+방향키는 10px 이동합니다. 오른쪽의 **선택 요소 복제 / 선택 요소 삭제**와 Delete도 묶음에 적용됩니다. 묶음 이동·복제·삭제는 실행 취소 한 번으로 되돌립니다. 기술이나 아이템 설명을 직접 배치하거나 복제하면 기술 자동 맞춤을 끄고 그 위치를 유지합니다.

여러 요소를 선택한 상태에서 하나를 클릭하면 단일 선택으로 바뀝니다. 크기 조절은 단일 선택에서 합니다. 드래그 중 Esc나 포인터 취소는 미리보기 이동을 버립니다. 선택만으로 파일이나 실행 취소 기록은 바뀌지 않으며 카드·앞뒷면을 전환하면 선택이 해제됩니다.

## 실물 용지와 바로 인쇄·PDF

**A4 용지 보기**에서 용지 치수, mm 눈금, 앞뒤 페이지, 빈 칸과 재단선을 확인합니다. 초기 A4 세로, 여백 6 mm, 간격 4 mm는 **3 × 3 / 한 면 9장**입니다. Letter와 가로 방향도 지원합니다.

**A4 꽉 채우기**는 간격을 0 mm로 바꾸고 카드가 가장 많이 들어가는 용지 방향을 고릅니다. 여백은 현재 값과 5 mm 중 작은 값을 유지하되, 더 많은 카드가 들어가는 경우 필요한 만큼 줄입니다. 카드 자체의 mm 크기와 카드별 수량은 유지합니다. 예를 들어 63 × 88 mm는 여백 5 mm로 한 면 9장, 67 × 88 mm는 여백 4.5 mm로 9장을 놓습니다. 한 장의 A4에 여러 카드를 인쇄해 재단선을 따라 직접 오리는 방식입니다.

전체 맞춤·배율은 화면 보기용입니다. **실제 크기 100%**와 **화면 자 보정**을 이용해 표시된 100 mm 선을 실제 자로 맞출 수 있습니다. 화면 보정은 프로젝트와 PDF 치수를 바꾸지 않습니다.

양면을 선택하면 바로 인쇄와 PDF의 페이지 순서는 **앞면 1 → 뒷면 1 → 앞면 2 → 뒷면 2**입니다. 실제 뒤집기 방향에 맞춰 뒷면 카드 위치만 반전하며, 그림과 글자는 거울상으로 만들지 않습니다. 뒷면 X/Y mm 보정으로 프린터 위치 차이를 조절할 수 있습니다. 마지막 페이지의 빈 칸도 대응합니다.

**바로 인쇄** 또는 **Ctrl+P / Cmd+P**를 누르면 PDF 파일을 만들거나 내려받지 않고 브라우저 인쇄창을 엽니다. A4/Letter, 용지 방향, 앞뒷면·수량, 재단선, 뒷면 X/Y 보정과 저장한 이펙트 장면을 그대로 사용합니다. 입력칸에 막 적은 수량도 반영합니다. 인쇄창에서 **실제 크기 / 배율 100%**, 선택한 용지와 방향, **머리글·바닥글 끄기**를 설정하고 양면이면 작업실과 같은 긴 쪽/짧은 쪽 넘김을 선택하세요. 자동 페이지 맞춤은 끄세요. 취소 후에도 편집을 계속하거나 다시 인쇄할 수 있습니다.

**PDF 만들기**는 저장해 둘 PDF 파일이 필요할 때 사용합니다. 바로 인쇄와 PDF 모두 모든 카드와 필요한 뒷면을 검사하고 약 300 dpi로 출력합니다. 작은 글자·넘치는 글자·빠진 기술 표시·카드 밖 요소 등의 안내가 있어도 현재 모습 그대로 출력합니다. 잘못된 자료나 용지에 카드를 배치할 수 없는 설정은 구체적으로 안내합니다. 한 번의 인쇄 계획은 최대 1000장 용지 묶음, 한 면 10000칸, 앞면 총 100000칸을 처리합니다. 더 큰 작업은 수량을 나누세요.

PDF 인쇄 창에서 **실제 크기 / 100%**, 선택한 **용지와 방향**, 양면이면 같은 **긴 변 / 짧은 변 뒤집기**를 설정합니다. 프린터의 자동 페이지 맞춤은 끄세요. 실제 프린터의 급지·여백 차이는 첫 한 장으로 확인하고 X/Y 보정을 맞추면 됩니다.

## 개발과 검증

개발용 Node.js 24와 프로젝트 의존성을 설치한 환경에서:

```text
npm ci
npm run verify
```

`verify` 한 번으로 새 빌드·버전 일치·기본 검사·오프라인 저장/불러오기·업데이트 경로를 차례로 검사합니다. 화면에는 결과·실패한 검사명·원인·보고서 위치만 출력합니다. 상세 로그와 JSON/Markdown 결과는 `artifacts/verification/실행시각/`에 보관합니다.

| 명령 | 반복 확인할 범위 |
| --- | --- |
| `npm run verify` | 모든 기본 검사 + 오프라인 편집·저장·다시 열기·업데이트 |
| `npm run verify:effects` | 기본 범위 + 6초 영상·취소·Esc·선택 재생·별빛·이펙트 되돌리기 |
| `npm run verify:print` | 기본 범위 + 직접 인쇄·A4 양면 PDF 치수와 픽셀·스프라이트 출력 |
| `npm run verify:full` | 저장소의 모든 기본·브라우저 검사 |

매번 현재 코드로 새로 실행하며 생략·취소·결과 집계 누락도 실패로 처리합니다. 검사 도중 소스나 배포 HTML이 바뀌면 통과를 취소합니다. 보고서에 버전·입력 코드 해시·HTML 해시를 기록하므로 이전 빌드의 성공과 구별할 수 있습니다. 검사는 순차 실행하며 같은 저장소에서 두 검증을 동시에 실행하지 마세요. 자동 배포나 개인 작업 파일 변경은 하지 않습니다. 새 기능의 시각적 완성도와 실제 장치 확인은 필요한 경우 따로 수행합니다.

검사 파일만 미리 확인하려면 `node scripts/verify.mjs --profile effects --list`를 사용합니다. 개별 개발 명령인 `test:unit`, `build`, `test:browser`도 계속 사용할 수 있습니다.

브라우저 테스트는 별도 프로필의 설치된 Edge를 사용하며 기본적으로 모든 HTTP/HTTPS 요청을 차단합니다. 업데이트 검사는 가짜 배포 응답만 제공하고 실제 서버에 접속하지 않습니다. 다른 Chromium 경로는 `CARD_BROWSER_PATH`로 지정할 수 있습니다. 검증 자료는 `artifacts/qa/`에 있습니다. PDF 검사에는 Python의 pypdf/Pillow, 시각 검토에는 Poppler를 사용합니다.

```text
python scripts/verify-pdf.py artifacts/qa/duplex.pdf
python scripts/verify-effects-pdf.py artifacts/qa/visual-effects-1.pdf --references artifacts/qa/effects-references.json
pdftoppm -png -r 150 artifacts/qa/duplex.pdf artifacts/qa/pdf-page
```

### 새 버전 배포 주소 연결

`release.json`의 버전·날짜·변경사항을 갱신하고 `package.json`의 버전과 맞춘 뒤 빌드합니다. 결과의 `card-print-studio.html`과 `update.json`을 같은 HTTPS 배포 폴더에 올립니다. `update.json`의 `downloadUrl`은 버전 정보 파일 기준 상대 주소도 지원합니다. 버전 정보는 `format: "card-print-studio-update"`, `version`, `downloadUrl`을 포함해야 합니다. `notes`와 `releasedAt`은 선택 사항입니다.

두 파일을 제공하는 서버는 외부 요청을 허용해야 합니다(`Access-Control-Allow-Origin: *`). 버전 정보는 최대 256KB/10초, HTML은 최대 64MB/60초까지 받습니다. HTML은 원본 바이트를 보존해 파일로 저장하므로 서버의 첨부파일 헤더가 없어도 됩니다. 로그인 정보가 들어간 주소와 HTTPS 이외의 주소는 받지 않습니다. 실패를 최신 버전으로 표시하지 않습니다.

`release.json`의 `sourceUrl`은 현재 `https://raw.githubusercontent.com/lolipop000000/card-print-studio/main/dist/update.json`에 연결되어 있습니다. 자동 확인은 기본 꺼짐입니다. 다음 버전은 `release.json`, `package.json`, `package-lock.json`의 버전을 함께 올리고 빌드한 뒤 `dist/`를 `main`에 게시하세요. 같은 버전 태그의 GitHub Release에도 HTML·사용법·라이선스·update.json을 첨부하면 위 최신 다운로드 링크에서 받을 수 있습니다. 개인 카드 파일과 `작업실 데이터/`는 저장소에 올리지 마세요.
